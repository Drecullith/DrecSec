# Contributing to DrecSec

DrecSec is early-stage and the contribution process will evolve with the project.

For now:

1. Keep changes small and reviewable.
2. Explain the problem before the solution.
3. Do not include secrets, personal data or private credentials.
4. Security demonstrations must use authorized or intentionally vulnerable targets.
5. Prefer accessible, dependency-light solutions unless a new dependency has a clear benefit.
6. Run the build before opening a pull request.

```bash
npm install
npm run typecheck
npm run build
```
