# DrecSec v0.2 Archive

DrecSec v0.2 briefly explored a community platform with Supabase authentication, member profiles, posts, and realtime chat.

That direction was intentionally retired after testing. DrecSec is now portfolio-first: no public accounts, no login, no credential collection, no realtime chat, and no database dependency.

The final v0.2 code remains preserved on the `archive/v0.2-community-experiment` branch for historical reference only.
