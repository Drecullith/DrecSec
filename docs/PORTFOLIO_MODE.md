# DrecSec portfolio mode

DrecSec is intentionally a public, portfolio-first website.

It does not require visitor accounts, passwords, member profiles, community posts, or live chat. The production site is a static React/Vite application deployed from GitHub to Vercel.

If a future feature genuinely requires server-side state, it should be introduced as a separate, narrowly scoped service with a fresh security review rather than restoring credential handling by default.
