# DrecSec Roadmap

DrecSec is being built in small, reviewable releases with the portfolio itself as the product.

## v0.1 — Portfolio foundation

- Responsive public portfolio
- Drecullith identity and project showcase
- Learning journey
- Security policy, architecture notes, and CI

## v0.2 — Auth/community experiment (archived)

- Supabase authentication and profile prototype
- Community posts and realtime chat prototype
- Retired after testing in favor of a simpler portfolio-only architecture
- Preserved on `archive/v0.2-community-experiment`

## v0.3 — Portfolio reboot

- Remove account creation, authentication, member profiles, community posting, and live chat
- Remove Supabase and all runtime database/realtime dependencies
- Keep the public site credential-free
- Keep GitHub → Vercel deployment, security headers, dependency auditing, typecheck, and production builds

## v0.4 — Project depth

- Individual project detail pages
- Screenshots, architecture notes, milestones, and lessons learned
- Better linking to source code and releases

## v0.5 — Verified activity and field notes

- GitHub contribution and project activity integrations
- Open-source contribution history
- Ethical-lab and CTF write-ups
- Sanitized methodology notes and defensive takeaways

## v1.0 — Portfolio release

- Security review
- Accessibility audit
- Performance pass
- Content polish
- Documentation and contributor guidance
