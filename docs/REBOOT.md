# DrecSec v0.3 Reboot

DrecSec v0.3 is a public cybersecurity portfolio.

## Principles

- No public accounts or login
- No password collection
- No member database
- No realtime chat
- No Supabase dependency
- Public, evidence-backed project and learning history
- Legal, permission-based security work only

The deployment architecture is intentionally simple: GitHub -> Vercel -> static public portfolio.
